# 工作流说明

![六步进攻路线](../assets/playbook.jpg)

## 为什么这样分工
- **patent-disclosure-skill**（上游 v5.1.0）擅长中文专利语境：挖点、国知局查新、交底书模板、Word 输出、申请四件套、对照表、审查答复。
- **PubMed / PQAI 脚本** 补国知局之外的盲区：医学方案最常被论文或美国专利破坏新颖性。
- **machine-skill** 擅长把结构变成可拆解、可剖切、跑真实物理公式的 3D 模型，给「技术效果」提供可解释的量化依据。
- **本仓库** 只做调度和规则，避免两个技能各写各的。

## 四条红线
1. **提前公开**：中国专利以申请日判断新颖性，宽限期只有第 24 条四种情形；期刊论文、预印本、GitHub、视频网页都不在其中。
2. **疾病诊疗方法**：专利法第 25 条排除；2023 版审查指南明确"全部步骤由计算机等装置实施的信息处理方法"不属于诊断方法。详见 `references/medical-subject-matter-v0.1.md`。
3. **仿真/模型冒充实验或临床结论**：审查与后续维权都看证据，仿真和回顾性验证只作辅助并标注来源。
4. **检索泄密**：对外检索只发关键词。

## 适用 / 不适用
- 适用：器械结构改进、机电装置、带算法的监测预警系统、评分/决策支持软件、工装夹具、手术导板。
- 部分适用：药物组合物、制药用途、动物造模装置（不走 machine-skill，第 2b 步重点把关）。
- 不适用：纯科学发现、纯生物机制、纯打分规则（无技术特征）。
